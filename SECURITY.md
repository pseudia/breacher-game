# Security Policy

If you find a security vulnerability in Breached, please report it privately by
email to <info@pseudia.eu> with the subject `Breached security`. Do not open a
public issue.

Please include a description of the problem, the steps to reproduce it and its
potential impact. We will acknowledge your report as soon as possible and keep
you informed of the fix.

Never include real personal data or credentials in issues, pull requests or
commits.
